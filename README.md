# React Stopwatch App

A simple stopwatch built using **React**. It allows users to start, pause, and reset the timer with a user-friendly interface.

---

## Features

- Start / Pause / Reset stopwatch
- Reset timer to 00:00:00
- Real-time update using `setInterval`
- React functional component using hooks
- Clean and minimal design

---

## Technologies Used

- React (with Hooks)
- JavaScript (ES6)
